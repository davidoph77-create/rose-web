# Rose V10-008 — Goal Engine V3

Cette version ajoute la gestion V10 des objectifs.

## Capacités

- création d'objectifs structurés ;
- priorité automatique ;
- statuts ;
- progression ;
- date cible ;
- tags ;
- analyse d'urgence ;
- détection du besoin de planification ;
- connexion optionnelle à Planner Engine V3 ;
- consultation optionnelle de Memory Engine V2 ;
- Runtime Module ;
- handler prêt pour un GoalAgent ;
- self-test complet.

## Principe

Un objectif peut désormais créer automatiquement un plan
et consulter les souvenirs pertinents avant de commencer.

Cette version ne remplace pas automatiquement les anciens objectifs
présents dans App.tsx ou Supabase.
